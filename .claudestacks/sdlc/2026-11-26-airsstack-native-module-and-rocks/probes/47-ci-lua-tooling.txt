10:Builds and installs Lua into the `.lua/` directory in the working directory.
11:Adds the `.lua/bin` to the `PATH` environment variable so `lua` can be called
12:directly in workflows.
44:When using Windows the following prerequisite action must be run before
45:building Lua: [`step-security/msvc-dev-cmd@v1`](https://github.com/step-security/msvc-dev-cmd). It is safe to
46:include this line on non-Windows platforms, as the action will do nothing in those cases.
47:
48:```yaml
49:- uses: step-security/msvc-dev-cmd@v1
50:- uses: leafo/gh-actions-lua@v13
51:```
59:Specifies the version of Lua to install. The version name instructs the action
60:where to download the source from.
61:
62:Examples of versions:
63:
64:* `"5.1.5"`
65:* `"5.2.4"`
66:* `"5.3.6"`
67:* `"5.4.9"`
68:* `"5.5.1"`
69:* `"luajit-2.0"`
70:* `"luajit-2.1"`
71:* `"luajit-master"`
72:* `"luajit-openresty"`
73:
74:The version specifies where the source is downloaded from:
75:
76:* `luajit-openresty` — will always pull master from https://github.com/openresty/luajit2
77:* `luajit-2.0`, `luajit-2.1`, `luajit-master` — pulls that branch from https://github.com/luajit/luajit
78:* Anything else starting with `luajit-` (eg. `luajit-2.0.5`) — pulls the `v`-prefixed release tag from https://github.com/openresty/luajit2, since upstream LuaJIT no longer publishes tags
79:* Anything else — from https://lua.org/ftp/
80:
81:**Version aliases**
82:
83:You can use shorthand `5.1`, `5.2`, `5.3`, `5.4`, `5.5`, `luajit` version aliases to point to the
84:latest (or recent) version of Lua for that version.

7:Builds and installs LuaRocks from source into the `.luarocks/` directory in the working directory. Configures `PATH`, `LUA_PATH`, and `LUA_CPATH` environment variables to be able to use the `luarocks` command directly in workflows, and require installed modules in Lua.
8:
9:[`leafo/gh-actions-lua`](https://github.com/marketplace/actions/install-lua-luajit) can be used to install Lua, which is required for LuaRocks to build and run. (This action will use any Lua installed in `.lua/`).
