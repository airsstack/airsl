- Latest release: 0.2.7 (GitHub tag 0.2.7; luarocks.org 0.2.7-1). Adds Lua 5.5 (CHANGELOG.md:3).
- Lua feature: from cfg.lua_version only (rust-mlua.lua:16-36): 5.4 -> lua54; 5.1 -> luajit when util.get_luajit_version() (or cfg.luajit_version) is non-nil, else lua51. Any other version -> 'Lua version X is not supported'. There is no rockspec knob to choose it; build.features only APPENDS (rust-mlua.lua:58-64).
- Command: 'cargo build --release' + each cargo_extra_args entry verbatim + '--target-dir=<target_path or "target">' + optional '--no-default-features' (only when build.default_features == false) + '--features <lua feature>[,extra features]' (rust-mlua.lua:43-67). Joined with spaces and run through fs.execute_env with LUA_ROCKSPEC_PACKAGE / LUA_ROCKSPEC_VERSION set (rust-mlua.lua:38-41,69). No --locked unless put in cargo_extra_args. No -p/--package unless put in cargo_extra_args.
- cwd: whatever directory luarocks is in when the driver runs (no chdir in the backend). See 21 for measured cwd (make: invocation dir; src rock: the unpacked source dir).
- Build fields read: cargo_extra_args, target_path, default_features, features, modules, include. Not read: source.dir (luarocks core uses it), any lua-version selection.
- Copy: for each modules entry, src = <target_path>/release/lib<name>.<external_lib_extension> (Windows: <modname>.<external_lib_extension>, i.e. no 'lib' prefix and named after the MODULE key, not the crate lib name), dst = <lib_dir>/<mod>.<lib_extension> (rust-mlua.lua:86-94). Error: 'Failed installing <src> in <dst>: <err>'.

development environment installed and try again." (rust-mlua.lua:10-13); luarocks prefixes 'Error: Build error: ' (observed in 24).
