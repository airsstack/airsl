=== findings
- --lr-cpath prints only the luarocks part: default '/Users/hiraq/.luarocks/lib/lua/5.4/?.so;/opt/homebrew/lib/lua/5.4/?.so'; with --tree the tree comes first; under LuaJIT the paths are lib/lua/5.1.
- 'luarocks config local_by_default' -> 'Error: Unknown entry local_by_default' exit 1 although the dump shows local_by_default = false (false values print as unknown; cmd/config.lua:133). Use 'luarocks config' dump or treat exit 1 as false.
- Without --tree/--local/--global/project: tree = last of rocks_trees (cmd.lua:142-144) = system /opt/homebrew on this homebrew config; /opt/homebrew is owned by the user, so a plain 'luarocks install' writes into /opt/homebrew (not executed).
- Unwritable tree: exit 2 (cmd.errorcodes.PERMISSIONDENIED, cmd.lua:47,775) with 'Error: <tree>/lib/luarocks/rocks-5.4 does not exist
and your user does not have write permissions in <tree>' + the '--local' / 'local_by_default' advice (fs/lua.lua:1226-1246).
