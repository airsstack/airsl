# Probe 189 — luarocks.org: are `airsstack` / `airsstack-luajit` taken; API answers to a bad/empty key; upload JSON shape
Question (P13, no credentials): (1) do the module names `airsstack` and `airsstack-luajit` already exist on luarocks.org?
(2) what does the API answer for an invalid key, an empty key, and `bearer` without/with a bogus header? (3) which JSON fields
do /api/1/:key/upload and /api/1/:key/upload_rock/:version_id return (source), incl. the version id the client reads?
Tools: curl 8.x (macOS system curl, User-Agent "probe-client"), Lua 5.4.8. Date-stamped below; luarocks.org answers are a snapshot.
