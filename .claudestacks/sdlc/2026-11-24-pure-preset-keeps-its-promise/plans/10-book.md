# The airsl Book documents host access Implementation Plan

**Goal:** Make the airsl Book describe host access exactly as the code now enforces it.

**Architecture:** Every change is a book page or a README. The rules are `CLAUDE.md` §
Documentation:
- write for a reader using airsl;
- each fact lives in one chapter, and other chapters link to it;
- every snippet and transcript is run against this checkout and pasted.

A new appendix F lists, function by function, what each surface loads. It is generated by running
`probes/globals.lua` (spec §12). The chapter list is spec §12's table.

**Tech Stack:** mdBook (`cargo make book-build`), the `airsl` binary built from this checkout.

**Content authority:** spec §3.1 (the host-modules-only paragraph), §6 (the `require` location
note), §8, §9, §12 (both tables and the ch09-03 and appendix F paragraphs).
