# Release airsl 0.2.0 and airsl-cli 0.2.0 Implementation Plan

**Goal:** Prepare both crates for publication together as 0.2.0.

**Architecture:** One release commit, as earlier releases used:
- it bumps both member versions and the root `[workspace.dependencies]` entry together
  (`workspace.md`; spec §13);
- it adds the CHANGELOG entry spec §12 names.

Tags and `cargo publish` (library first) stay with the author after merge (spec §13).

**Tech Stack:** Cargo, cargo-make (`dod`, `examples`, `book-build`, `publish-dry-run`).

**Content authority:** spec §12 (the CHANGELOG row), §13, §14.

---

## Files that change

```
crates/airsl/Cargo.toml       — modify: version 0.2.0
crates/airsl-cli/Cargo.toml   — modify: version 0.2.0
Cargo.toml                    — modify: [workspace.dependencies] airsl version 0.2.0
Cargo.lock                    — modify: regenerated by the build
CHANGELOG.md                  — modify: the airsl 0.2.0 — airsl-cli 0.2.0 entry
```

## Order of work

### Task 1 — Bump both crates to 0.2.0 and record the release

**Files:**
- Modify `crates/airsl/Cargo.toml:4` and `crates/airsl-cli/Cargo.toml:4`: `version = "0.2.0"`.
- Modify `Cargo.toml:56`: `airsl = { version = "0.2.0", path = "crates/airsl" }`.
- `Cargo.lock` is regenerated by the first build.
- Modify `CHANGELOG.md`: a new top entry, `## airsl 0.2.0 — airsl-cli 0.2.0 — YYYY-MM-DD`, with the release commit's date,
  in the same form as the 0.1.6 entry (`CHANGELOG.md:12`).
  Its first line says this is a breaking release, so both crates take a middle-number bump (the
  file's own SemVer note). It has these sections:
  - **Breaking.** `pure` withholds `print`, refuses stdio, `hook`, the clock, named zones, a
    relative `path.absolute` and a seedless `math.randomseed`, and gives a refusing `require`.
    `math.random` repeats per fresh engine. `GrantSet::declared()` now holds host access.
  - **Added.** `HostAccess`, `GrantSet::sealed`/`with_access`/`allows`/`access`,
    `Error::RequireDenied`, `--allow-access`, `doctor` taking the grant flags, and book
    appendix F.
  - **Changed.** Every row of spec §14: the no-roots refusal text and variant, the `grants:` lines,
    and the `ext.granted().access` key.

  The entry links the book's ch09-03 and ch06-03, and names issues #11, #12, #13 and #14.

**Change:** Versions and the changelog only.

**Proof:**
- `cargo metadata --format-version 1` resolves both crates at 0.2.0 (`workspace.md`'s workspace
  check).
- `cargo make publish-dry-run` passes.

**Done when:** `cargo make dod`, `cargo make examples` and `cargo make book-build` pass. Commit
`chore(release): airsl 0.2.0 and airsl-cli 0.2.0`.

## Risks

- **Changelog accuracy.** The changelog is the one place every user-visible change is listed. It
  is written from spec §14 and the merged plans, not from memory, and checked against the final
  diff.
- **Publishing.** It is the author's act: the library first, then the binary, whose lockfile pins
  it (spec §13). Nothing here publishes.

## Proof

- `cargo make dod`, `cargo make examples`, `cargo make book-build` and `cargo make publish-dry-run`
  are green.
- `cargo run -p airsl-cli -- --version` prints `airsl 0.2.0`.
